# Practical Tools Mobile

## Product context

- Audience: operators and analysts who use the existing Practical Tools Online center service from Android phones while moving between stores, collection work, and data review.
- Core jobs: sign in to a configured center service, trigger and inspect page collection, browse captured images, review analysis data, diagnose connectivity, and manage the session.
- Usage context: one-handed phone use on variable mobile/Wi-Fi networks, with occasional larger Android devices and split-screen windows. The app must remain useful when the network is slow or intermittently unavailable.
- Platform: native Android first. Web content is an explicit fallback for a feature that genuinely requires browser rendering; it is not the default surface.
- Product voice: calm, direct, compact, and operational. The user is competent; avoid tutorial copy and obvious explanations.
- Success: users can understand the current state in seconds, act without layout surprises, return from detail screens without losing context, and trust that images and data are loaded at their true available quality.
