策划实用小工具·Windows 绿色免安装中心

1. 将整个 PracticalToolsOnlinePortable 目录解压到普通可写目录，例如 D:\PracticalToolsOnlinePortable。
2. 双击 START.cmd。首次启动时，粘贴「主图一条龙服务协同版」在中心电脑上的实际运行目录。
3. 程序会自动读取已有 PostgreSQL 连接配置，并保存到本目录 .env；后续启动不再询问。
4. 保持黑色窗口开启，浏览器访问 https://collab.wnnttzy.kdns.fr/。
5. 管理员登录后，访问 https://collab.wnnttzy.kdns.fr/admin/ 可配置 COS、上传在线更新包和执行历史数据迁移。
6. 不需安装 Python、PostgreSQL 或 Windows 服务；不写注册表。停止时双击 STOP.cmd，或关闭启动窗口。
